# 01 - Layered carbon: dimensional rescue

This controlled C192 four-layer structure separates graph connectivity from hopping kinetics.

```bash
bash examples/paper/01_carbon_stack/run.sh
```

The EHT subspace is one local C `2pz` orbital per carbon. The important material-informed quantity is the ratio between interlayer and intralayer couplings. For transport rates based on explicit transfer integrals, the corresponding rate scale is approximately `(J_inter/J_intra)^2`.

The broader interlayer-coupling sweep in the paper is a mechanism map. The EHT value is an anchor on that map, not a fitted parameter.
