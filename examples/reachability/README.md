# Reachability example

This example performs graph connectivity only. No KMC waiting times are sampled.

From the repository root:

```bash
hopping3d examples/reachability/params.json
```

The result is written to:

```text
examples/reachability/results/reachability.json
```

The main quantities are the fraction of source sites connected to the drain and whether every source site can reach the drain.
