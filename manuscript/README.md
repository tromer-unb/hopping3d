# Manuscript source

This directory contains the LaTeX source associated with the article supported by this repository. The numerical engine is an extension of an earlier trajectory-resolved 2D hopping framework.

The simulation figures can be regenerated from the repository root with `bash reproduction/reproduce.sh quick` (smoke/illustrative statistics) or `bash reproduction/reproduce.sh full` (production statistics). The manuscript source is kept here to make the mapping between model equations, simulation parameters, and figure-generation scripts explicit.
